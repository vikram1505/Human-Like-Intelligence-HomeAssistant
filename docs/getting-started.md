# Getting started

1. Install HLI with HACS or copy `custom_components/hli` manually.
2. Restart Home Assistant.
3. Add **Human-Like Intelligence** from Devices & services.
4. Open the new HLI entities.

HLI uses your existing Home Assistant Areas. For best results, assign devices to Areas in Home Assistant. No entity renaming is required.

HLI is read-only: installing it does not turn lights, switches, locks, HVAC or other equipment on or off.
